# Floodlight FC

A Godot 4.5.1-ready football prototype built from the original GodotBasic3DFootball study project.

## Features
- Updated to Godot 4-compatible GDScript conventions
- 3D pitch, players, ball, and HUD
- Score tracking and reset controls
- Refined prototype gameplay flow

## Controls
- Player 1: Arrow keys + Tab jump
- Player 2: W/A/S/D + Space jump
- R: reset positions
- N: reset match score
- Esc: quit

## Notes
This is still a prototype foundation for a marketable indie football experience, not a full AAA football game.
