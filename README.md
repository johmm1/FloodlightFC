# Floodlight FC

A Godot 4.5.1-ready football prototype built from the original GodotBasic3DFootball study project.

## Overview
This is a small, playable football prototype created to upgrade the original 2018 Godot project into the Godot 4.5.1 ecosystem.

## Features
- Godot 4.5 compatible project configuration
- Updated movement code for CharacterBody3D
- Basic match flow with score display and reset controls
- Simple 3D pitch, ball, and two-player prototype

## Controls
- Player 1: Arrow keys + Tab jump
- Player 2: W/A/S/D + Space jump
- R: reset position
- N: reset score
- Esc: quit

## Notes
This is an upgraded foundation for a marketable indie football game. It is not yet a full AAA football title.
